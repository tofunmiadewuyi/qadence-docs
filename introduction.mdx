## Get Up and Running in Three Steps

<Steps>
  <Step title="Get Your API Key">
    Log in to the [Check dashboard](https://wearecheck.com) and navigate to **Settings → API Keys**. Generate a new key and copy it somewhere safe — you'll need it for every request.
  </Step>
  <Step title="Make Your First Call">
    Use your API key as a Bearer token in the `Authorization` header to call any Check endpoint. Start with `GET /checks` to confirm your credentials work and see your existing checks.

    ```bash
    curl https://api.wearecheck.com/v1/checks \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```
  </Step>
  <Step title="Go Live">
    Once you've verified your integration in a test environment, swap in your production API key and point your webhook endpoint to a public URL. Check will start delivering real-time events to your system.
  </Step>
</Steps>
