Webhooks let you receive real-time event notifications from Check delivered directly to your server. Manage your webhook endpoints via the API — register a URL to start receiving events, list your existing endpoints, or delete one to stop delivery. When an event occurs (such as a result completing), Check sends an HTTP `POST` request with a JSON payload to each registered URL that is subscribed to that event type.

---

## Register a webhook

Registers a new webhook endpoint. On success, the response includes a `secret` — a signing key you can use to verify that incoming webhook requests genuinely originate from Check.

<ParamField body="url" type="string" required>
  The HTTPS URL where Check will deliver event payloads. Must use `https://`.
</ParamField>

<ParamField body="events" type="array" required>
  An array of event type strings to subscribe to. Supported values:
  - `check.created` — fired when a new check is created
  - `check.updated` — fired when a check is updated
  - `result.created` — fired when a new result is created
  - `result.completed` — fired when a result reaches a terminal state (`pass` or `fail`)
</ParamField>

```bash curl
curl -X POST https://api.wearecheck.com/v1/webhooks \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://yourapp.com/webhooks/check",
    "events": ["result.completed"]
  }'
```

**Example response — 201 Created**

```json
{
  "data": {
    "id": "wh_01HXYZ999",
    "url": "https://yourapp.com/webhooks/check",
    "events": ["result.completed"],
    "secret": "whsec_xxxxxxxxxxxxxxxxxxxx",
    "created_at": "2024-01-15T16:00:00Z"
  }
}
```

<ResponseField name="data" type="object">
  The newly created webhook object.

  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Unique identifier for the webhook endpoint, prefixed with `wh_`.
    </ResponseField>
    <ResponseField name="url" type="string">
      The HTTPS URL registered to receive event payloads.
    </ResponseField>
    <ResponseField name="events" type="array">
      The list of event types this endpoint is subscribed to.
    </ResponseField>
    <ResponseField name="secret" type="string">
      A signing secret prefixed with `whsec_`. Use this to verify the signature of incoming webhook requests. Only returned on creation.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the webhook was registered.
    </ResponseField>
  </Expandable>
</ResponseField>

<Warning>
  Store the `secret` returned on creation — it is only shown once and cannot be retrieved again. If you lose it, delete the webhook and register a new one.
</Warning>

## List webhooks

Returns a list of all registered webhook endpoints in your account. For security, the `secret` field is not included in list responses.

```bash curl
curl https://api.wearecheck.com/v1/webhooks \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**Example response — 200 OK**

```json
{
  "data": [
    {
      "id": "wh_01HXYZ999",
      "url": "https://yourapp.com/webhooks/check",
      "events": ["result.completed"],
      "created_at": "2024-01-15T16:00:00Z"
    }
  ]
}
```

<ResponseField name="data" type="array">
  An array of webhook objects. The `secret` field is omitted from each object for security.

  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Unique identifier for the webhook endpoint, prefixed with `wh_`.
    </ResponseField>
    <ResponseField name="url" type="string">
      The HTTPS URL registered to receive event payloads.
    </ResponseField>
    <ResponseField name="events" type="array">
      The list of event types this endpoint is subscribed to.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the webhook was registered.
    </ResponseField>
  </Expandable>
</ResponseField>

## Delete a webhook

Permanently deletes a registered webhook endpoint. Returns `204 No Content` on success with no response body.

<ParamField path="id" type="string" required>
  The unique identifier of the webhook endpoint to delete. Must be prefixed with `wh_`.
</ParamField>

```bash curl
curl -X DELETE https://api.wearecheck.com/v1/webhooks/wh_01HXYZ999 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**Response — 204 No Content**

No body is returned on successful deletion.

<Note>
  Deleting a webhook immediately stops event delivery to that URL. Any in-flight events that have already been dispatched may still arrive, but no new events will be sent after deletion.
</Note>
