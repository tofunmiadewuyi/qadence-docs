title: "Results API Endpoints Reference"
sidebarTitle: "Results"
description: "List and retrieve check results via the Check API. Filter by check ID or status to query verdicts, flags, and completion times."
---

Results represent the outcome of running a check. Each result is linked to a check and carries a status — `pending`, `pass`, or `fail` — along with a structured data payload containing a summary and any raised flags. Results are read-only: they are created automatically by the Check platform when a check is run, and cannot be created or modified via the API. Use the endpoints below to query and retrieve them.

---

## List all results

<ParamField query="page" type="integer">
  The page number to return. Defaults to `1`.
</ParamField>

<ParamField query="per_page" type="integer">
  Number of results per page. Defaults to `20`. Maximum is `100`.
</ParamField>

<ParamField query="check_id" type="string">
  Filter results to those belonging to a specific check. Use the `chk_` prefixed ID.
</ParamField>

<ParamField query="status" type="string">
  Filter results by status. Accepted values: `pending`, `pass`, `fail`.
</ParamField>

Returns a paginated list of results, ordered by creation date descending. Use `check_id` to scope results to a single check.

```bash curl
curl "https://api.wearecheck.com/v1/results?check_id=chk_01HXYZ123&status=pass" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**Example response — 200 OK**

```json
{
  "data": [
    {
      "id": "res_01HXYZ789",
      "check_id": "chk_01HXYZ123",
      "status": "pass",
      "data": {
        "summary": "All checks passed",
        "flags": []
      },
      "created_at": "2024-01-15T15:00:00Z",
      "completed_at": "2024-01-15T15:02:30Z"
    }
  ],
  "meta": {
    "page": 1,
    "per_page": 20,
    "total": 1
  }
}
```

<ResponseField name="data" type="array">
  An array of result objects.

  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Unique identifier for the result, prefixed with `res_`.
    </ResponseField>
    <ResponseField name="check_id" type="string">
      The ID of the check this result belongs to.
    </ResponseField>
    <ResponseField name="status" type="string">
      The outcome of the check. One of `pending`, `pass`, or `fail`.
    </ResponseField>
    <ResponseField name="data" type="object">
      Structured payload containing the verdict details.

      <Expandable title="properties">
        <ResponseField name="summary" type="string">
          A human-readable summary of the result.
        </ResponseField>
        <ResponseField name="flags" type="array">
          A list of flags raised during the check. Empty when no issues were found.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the result was created.
    </ResponseField>
    <ResponseField name="completed_at" type="string">
      ISO 8601 timestamp of when the result reached a terminal state (`pass` or `fail`). `null` if still `pending`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata.

  <Expandable title="properties">
    <ResponseField name="page" type="integer">
      The current page number.
    </ResponseField>
    <ResponseField name="per_page" type="integer">
      Number of items per page.
    </ResponseField>
    <ResponseField name="total" type="integer">
      Total number of results matching the query.
    </ResponseField>
  </Expandable>
</ResponseField>

## Get a result

<ParamField path="id" type="string" required>
  The unique identifier of the result to retrieve. Must be prefixed with `res_`.
</ParamField>

Retrieves a single result by its ID, including the full data payload and completion timestamp.

```bash curl
curl https://api.wearecheck.com/v1/results/res_01HXYZ789 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

**Example response — 200 OK**

```json
{
  "data": {
    "id": "res_01HXYZ789",
    "check_id": "chk_01HXYZ123",
    "status": "pass",
    "data": {
      "summary": "All checks passed",
      "flags": []
    },
    "created_at": "2024-01-15T15:00:00Z",
    "completed_at": "2024-01-15T15:02:30Z"
  }
}
```
